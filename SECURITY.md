# Security Policy

[中文版](docs/zh-CN/SECURITY.md)

## Reporting a Vulnerability

As a project focused on security hardening, we take security reports seriously.

If you discover a security issue related to this repository (e.g., a malicious link, compromised resource, or supply chain concern), please report it responsibly:

**Email:** [security@agentichardening.ai](mailto:security@agentichardening.ai)

Please include:

- Description of the issue
- Steps to reproduce (if applicable)
- The specific resource or link involved
- Any potential impact assessment

## Response Timeline

- **Acknowledgment**: Within 48 hours
- **Initial assessment**: Within 5 business days
- **Resolution**: Dependent on severity, typically within 14 days

## Scope

This security policy covers:

- Malicious or compromised links in the curated list
- Supply chain risks in recommended tools or frameworks
- Vulnerabilities in any project infrastructure (website, CI/CD)

## Recognition

We appreciate responsible disclosure and will acknowledge security reporters in our project (with your permission).
