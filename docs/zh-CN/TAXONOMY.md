# 分类体系与设计理念

[English](../TAXONOMY.md)

## 设计理念

本 awesome 列表沿 **"攻击面 → 加固手段 → 评估验证 → 治理标准"** 主线组织资源。这种结构确保：

1. **红队人员** 可以快速找到威胁情报和攻击技术（类别 1–5）
2. **蓝队人员** 可以为每种威胁找到对应的防御手段（类别 6–9）
3. **安全工程师** 可以验证防御措施的有效性（类别 10–11）
4. **合规官员** 可以找到治理框架（类别 12）

"Hardening"（加固）——项目的核心定位——贯穿每个章节：每个威胁类别都映射到具体的加固技术。
