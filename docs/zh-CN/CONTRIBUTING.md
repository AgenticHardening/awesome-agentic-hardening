# 贡献指南

[English](../../CONTRIBUTING.md)

感谢你有兴趣为 awesome-agentic-hardening 做出贡献！本项目旨在成为 Agentic AI 安全加固领域最全面、最有条理的资源集合。

## 如何贡献

### 添加资源

1. **Fork** 本仓库
2. 将你的资源添加到 `README.md` 和 `README_zh-CN.md` 中的相应类别
3. 提交 **Pull Request**

### 资源格式

每条资源应遵循以下格式：

```markdown
| [资源名称](URL) | 类型 | 简要描述（一句话） |
```

**类型** 应为以下之一：
- `📄 论文` — 学术论文或技术报告
- `🔧 工具` — 开源工具或代码库
- `📦 框架` — 安全框架或平台
- `📖 指南` — 教程、指南或最佳实践文档
- `📊 数据集` — 数据集或评测基准
- `🎯 CTF` — CTF 挑战赛或红队演练
- `📋 标准` — 行业标准或合规框架
- `🎥 演讲` — 会议演讲或视频
- `📝 博客` — 博客文章

### 质量标准

提交前，请确保你的资源：

- [ ] 与 **Agentic AI 安全** 直接相关（而非通用的 LLM 安全）
- [ ] 放置在 **正确的类别** 中（参考类别描述）
- [ ] 链接 **有效** 且指向原始来源
- [ ] 包含 **清晰简洁** 的英文描述
- [ ] **不是** 已有条目的重复
- [ ] 在其类别中按 **字母顺序** 排列

### 类别指南

我们的分类体系遵循 **"攻击面 → 加固手段 → 评估验证 → 治理标准"** 主线：

| 类别范围 | 关注领域 |
|----------|----------|
| 1–5 | **威胁与攻击面** — 攻击向量与威胁建模 |
| 6–9 | **加固技术** — 防御措施与控制 |
| 10–11 | **评估与测试** — 基准评测与验证 |
| 12 | **治理与标准** — 政策与合规 |

如果你不确定资源应归入哪个类别，可以在 PR 描述中说明，我们会协助分类。

### 双语要求

本项目同时维护英文版（`README.md`）和中文版（`README_zh-CN.md`）。添加资源时：

- **必须** 将条目添加到 `README.md`（英文版）
- **可选** 将翻译后的条目添加到 `README_zh-CN.md`（中文版）——维护者可以协助翻译

## 建议新类别

如果你认为需要新的类别：

1. 使用 "Category Proposal" 模板创建 **Issue**
2. 描述类别范围及现有类别无法覆盖的原因
3. 提供至少 3 个适合该类别的示例资源

## 报告问题

- **失效链接**：使用 "Broken Link" 模板创建 Issue
- **分类错误**：创建 Issue 或提交 PR 进行修正
- **重复条目**：创建 Issue 并注明两个条目

## 行为准则

请阅读并遵守我们的[行为准则](../../CODE_OF_CONDUCT.md)。

## Pull Request 流程

1. 确保你的更改通过自动化链接检查
2. 如适用，请更新两个语言版本
3. 建议每个 PR 只添加一个资源，以加快审核速度
4. 批量添加（如某次会议的所有论文）可接受，但需要清晰的描述

## 致谢

所有贡献者都将在项目中获得认可。感谢你帮助提升 Agentic AI 系统的安全性！🛡️
