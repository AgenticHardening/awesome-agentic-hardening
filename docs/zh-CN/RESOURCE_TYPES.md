# 资源类型定义

[English](../RESOURCE_TYPES.md)

本文档定义了 awesome 列表中使用的资源类型。

## 类型图标与定义

| 图标 | 类型 | 定义 | 示例 |
|------|------|------|------|
| 📄 | 论文 | 经过同行评审的学术论文或来自知名机构的技术报告 | arXiv、IEEE、ACM 出版物 |
| 🔧 | 工具 | 开源工具、代码库或 CLI 工具 | 包含可用代码的 GitHub 仓库 |
| 📦 | 框架 | 综合性安全框架或平台 | 多组件安全解决方案 |
| 📖 | 指南 | 教程、操作指南或最佳实践文档 | OWASP 指南、厂商文档 |
| 📊 | 数据集 | 公开可用的数据集或评测基准 | 攻击/防御数据集、CTF 数据 |
| 🎯 | CTF | 夺旗赛挑战或红队演练 | 安全竞赛、挑战题集 |
| 📋 | 标准 | 行业标准、合规框架或法规 | NIST、ISO、CSA 标准 |
| 🎥 | 演讲 | 会议演讲、主题报告或视频教程 | DEF CON、Black Hat、学术演讲 |
| 📝 | 博客 | 博客文章或深度分析 | 技术博客、案例研究 |

## 收录标准

资源被收录需满足以下**所有**条件：

1. **相关性**：与 Agentic AI 安全直接相关（非通用 LLM 或传统网络安全）
2. **质量**：来自有信誉的来源，内容有实质性
3. **可访问性**：公开可访问（优先收录免费或开放获取的资源）
4. **时效性**：近 3 年内发布或更新（基础性著作例外）
5. **原创性**：原始来源，而非对已有内容的总结或转载
