# Resource Type Definitions

[中文版](zh-CN/RESOURCE_TYPES.md)

This document defines the resource types used throughout the awesome list.

## Type Icons & Definitions

| Icon | Type | Definition | Example |
|------|------|------------|---------|
| 📄 | Paper | Peer-reviewed academic paper or technical report from a recognized institution | arXiv, IEEE, ACM publications |
| 🔧 | Tool | Open-source tool, library, or CLI utility | GitHub repositories with working code |
| 📦 | Framework | Comprehensive security framework or platform | Multi-component security solutions |
| 📖 | Guide | Tutorial, how-to guide, or best practice document | OWASP guides, vendor documentation |
| 📊 | Dataset | Publicly available dataset or evaluation benchmark | Attack/defense datasets, CTF data |
| 🎯 | CTF | Capture The Flag challenge or red team exercise | Security competitions, challenge sets |
| 📋 | Standard | Industry standard, compliance framework, or regulation | NIST, ISO, CSA standards |
| 🎥 | Talk | Conference presentation, keynote, or video tutorial | DEF CON, Black Hat, academic talks |
| 📝 | Blog | Blog post, article, or in-depth analysis | Technical blog posts, case studies |

## Selection Criteria

For a resource to be included, it should meet **all** of the following:

1. **Relevance**: Directly related to agentic AI security (not general LLM or traditional cybersecurity)
2. **Quality**: From a reputable source with substantive content
3. **Accessibility**: Publicly accessible (free or open-access preferred)
4. **Currency**: Published or updated within the last 3 years (exceptions for foundational works)
5. **Originality**: Primary source, not a summary or re-post of existing content
